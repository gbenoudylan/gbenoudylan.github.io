BudgetTracker Web

Un tableau de bord React et Supabase, avec connexion sans mot de passe par lien magique. L'isolation des données est garantie au niveau de la base : un utilisateur ne peut ni lire ni modifier les lignes d'un autre, même si l'interface était contournée.

  • Sans mot de passeconnexion par lien magique envoyé par e-mail
  • Dans la basel'isolation des données ne dépend pas de l'interface
  • En ligneapplication déployée, démo ouverte à tous

Le choix qui compte

Cacher les données d'un autre utilisateur dans l'interface ne suffit pas : quelqu'un qui contourne l'interface les verrait quand même. J'ai donc placé la règle dans la base de données elle-même, avec les politiques Row Level Security de Supabase. Chaque ligne appartient à un utilisateur, et la base refuse tout le reste.

Chaque utilisateur ne voit que ses lignes. La règle vit dans la base, pas dans l'interface.
