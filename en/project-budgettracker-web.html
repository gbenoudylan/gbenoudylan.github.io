P-05Personal project

BudgetTracker Web

A React and Supabase dashboard with passwordless sign-in by magic link. Data isolation is enforced at database level: a user can neither read nor change another user's rows, even if the interface were bypassed.

  • Passwordlesssign-in by magic link sent by email
  • In the databasedata isolation does not depend on the interface
  • Livedeployed application, demo open to everyone
Demo data
01

The problem

Hiding another user's data in the interface isn't enough: anyone who bypasses the interface would still see it.

02

The choice that matters

I put the rule in the database itself, with Supabase Row Level Security policies. Every row belongs to a user and the database refuses everything else. Sign-in is passwordless, through a magic link sent by email.

03

The chosen architecture

04

Screenshot

05

What I take from it

The rule lives in the database, not in the interface.

Protection that depends on the screen can be bypassed. Protection placed as close to the data as possible holds even if the interface does not.
