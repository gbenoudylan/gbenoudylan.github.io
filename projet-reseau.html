Maquette réseau en trois niveaux

Architecture d'entreprise hiérarchique modélisée sous Cisco Packet Tracer, inspirée d'un site réel. Les noms d'hôtes, l'adressage et les accès réels ont été remplacés par des valeurs génériques.

  • 2routeurs de bordure C8200L, pour la redondance
  • 9switches d'accès C9200, chacun relié à deux switches de distribution
  • 4couches : bordure, cœur, distribution, accès

Une couche, un rôle

  • La bordure relie l'entreprise à Internet avec deux routeurs C8200L, pour qu'une panne n'isole pas le site.
  • Le cœur est une pile de switches C9300X, qui transporte le trafic entre les étages.
  • La distribution est une pile C3850, qui applique le routage entre VLAN et les règles d'accès.
  • L'accès regroupe neuf switches C9200, chacun relié à deux switches de distribution : si un lien tombe, le trafic passe par l'autre.
