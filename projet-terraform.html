Lab multi-cloud avec Terraform

Un réseau AWS décrit entièrement en code, avec une passerelle VPN IPSec prévue vers Azure. J'ai tout déployé, observé, puis détruit pour ne rien laisser tourner.

  • 15ressources AWS décrites en code
  • 0accès public sur le bucket S3

Ce que j'ai construit

Un VPC AWS avec un sous-réseau public, un serveur web, un bucket S3 fermé à tout accès public, et une passerelle VPN. Tout est décrit en Terraform : je peux le recréer ou le détruire en une commande.

Ce qui n'a pas marché

Le tunnel est créé côté AWS mais n'est jamais monté, faute de pouvoir synchroniser la clé partagée avec Azure en offre gratuite. Je le dis tel que je l'ai observé : le lab a servi à comprendre ce qui bloque, et le résultat n'est pas un tunnel fonctionnel.

AWS décrit dans le code, Azure en extrémité distante.
